Knowledge Guide | 现代生活知识手册

一个基于 Vue 3 + Vite 构建的现代知识类网站，提供健康、旅行、美食、动物等多个主题的分类浏览与文章阅读。
本项目采用响应式设计，页面布局使用流式布局方式，并结合 CSS 媒体查询（media query）对不同屏幕尺寸进行适配，确保在 PC 端与移动端均能正常显示与使用。

核心功能：
主题分类首页：展示健康、旅行、美食、动物等主题的文章列表。
文章详情页：针对阅读体验优化的页面（舒适排版、自动夜间模式适配）。
全局导航栏：固定导航，包含主题切换（亮色/暗色）和快速分类入口。
响应式布局：适配桌面端与移动端设备。
全局主题与字体：支持一键切换白天/夜间主题，并使用自定义字体。


响应式设计与异常处理说明
一、响应式设计（Responsive Design）
本项目在样式设计阶段充分考虑了不同设备与屏幕尺寸的适配问题，主要体现在以下几个方面：
1自适应布局：
页面整体采用弹性布局与百分比宽度（如 width: 100%），避免使用固定宽高，保证在不同分辨率下均能正常显示。
根节点 #app 与主要容器均支持自适应屏幕宽度。

2媒体查询适配：
使用 @media (max-width: 768px) 针对移动端设备进行样式调整。
在小屏幕下适当减小标题字号、卡片内边距，并将按钮设置为全宽显示，提高移动端可读性与可操作性。

3图片自适应：
全局设置 img { max-width: 100%; height: auto; }，确保图片在不同屏幕尺寸下不会溢出容器或导致布局错乱。
深色 / 浅色主题兼容
通过 CSS 变量与 data-theme 属性实现深色与浅色主题切换，适配不同使用环境和用户偏好。

二、异常处理（Robustness & Fault Tolerance）

项目在前端实现中对可能出现的异常情况进行了合理处理：
1样式层面的异常防护：
统一设置全局字体兜底方案（sans-serif），避免自定义字体加载失败导致页面异常。
使用 CSS 变量管理颜色与背景，防止主题切换时样式错乱。

2内容显示异常防护：
图片尺寸自适应，避免因图片比例异常导致页面结构破坏。
文本区域设置行高与最大显示行数，防止内容过长影响整体布局。

3交互与显示稳定性
页面切换时通过路由配置统一回到页面顶部，避免出现滚动位置异常。
各组件在未加载或内容为空的情况下仍能保持页面结构稳定。

 环境准备
Node.js** (>= 18.x)
管理工具：npm 

运行项目步骤
1.  克隆项目
    ```bash
    git clone <仓库地址>
    cd modern-knowledge-guide
    ```

2.  安装依赖
    ```bash
    npm install
    ```

3.  启动开发服务器
    ```bash
    npm run dev
    ```
    启动后，在浏览器中访问 `http://localhost:5173`。

4.  构建生产版本 (可选)
    ```bash
    npm run build
    ```
    构建产物将生成在 `dist/` 目录下。

 样式与主题

- 全局字体：在 `style.css` 中定义，自动应用于全站。
- 夜间模式：通过 `data-theme` 属性 (`light` / `dark`) 进行切换，CSS 变量提供样式支持。
